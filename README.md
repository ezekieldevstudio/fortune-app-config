# Fortune App public configuration repository

Public files for the Fortune App:

- `faq.json` — Korean FAQ.
- `notices.json` — Notices; the initial development notice is disabled.
- `privacy-policy.html` — English Privacy Policy, intended to be served through GitHub Pages.

The app is under development. **Fortune is a temporary name; the final app name is not yet confirmed.** Remote `fortune.json` is not currently used. Fortune content/config may be added in the future.
